# voxel-modeling

## Purpose
Owns the recommended geometry techniques for the voxel-inspired style:
chunky boxes, beveled boxes, simple cylinders, low-poly curves, roofs,
pipes, wheels and repeated structures — plus the geometry to avoid.

## When to use
When writing an `asset.py` builder, choosing how to construct a part, or
optimizing geometry that reads wrong at gameplay zoom.

## Non-goals
Dimensions (`asset-scale`), colour (`material-palette`), triangle caps and
cleanup passes (`mesh-optimization`), rigging/animation
(`animation-authoring`).

## Dependencies
- `art/railroad_art/` primitives: boxes, beveled boxes, cylinders, roofs,
  pipes, wheels, frames, boilers, cabs, chimneys, placement helpers,
  vertex-colour assignment, LOD assembly, export.
- `asset-scale` for every size argument passed to those primitives.

## Invariants
1. Common construction goes through `railroad_art` primitives; direct
   `bpy` mesh-data manipulation is reserved for cases the abstraction cannot
   express (the art-authoring spec requires a locomotive authored from
   primitives only).
2. All edges are axis-aligned or 45° in plan view — curves are low-poly
   approximations, matching the tile grid's diagonal language.
3. Bevels are small and uniform (project decision ≈ 0.01–0.02 units); no
   subdivision surfaces, no subsurf-applied blobs.
4. Nothing intersects the terrain plane below Z = 0 except deliberate
   skirt geometry; no hidden interior geometry ships in a GLB.
5. Repeated structures (fence posts, tie rows, window rows) are generated by
   loops/instancing in the builder, not hand-placed.

## Public interfaces
`railroad_art` calls in an `asset.py` look like:

```python
train.frame(length=0.85)
train.boiler(radius=0.14)
train.cab(width=0.24)
train.chimney(height=0.22)
train.add_driving_wheels(count=2, radius=0.11)
train.add_leading_wheels(count=2, radius=0.06)
```

## Implementation rules
- Model big→small: block out readable volumes, check silhouette, then add
  one level of secondary detail max.
- Cylinders: 8–12 sides at most; boilers read fine at 10.
- Roofs: gable/hip from explicit quads; no solidify+boolean roof disasters —
  prefer simple CSG-free construction.
- Wheels are separate named objects (animation attaches to them); coupling
  rods may be one thin box per side.
- Merge coplanar faces and delete hidden geometry **before** LOD generation,
  not after.
- Avoid: n-gons spanning silhouette edges, non-uniform scale on mesh data,
  tiny geometry under ~0.02 units, complex texture-UV workflows (textures are
  exceptional by design).

## Validation
`python tools/rr.py art validate <id>` catches budget/origin/materials;
`art preview <id>` from all 8 angles exposes pinched silhouettes and clipping
that numbers miss.

## Common mistakes
- Reaching for modifiers (subsurf/bevel on everything) instead of authored
  chunky geometry — bloats triangle counts and loses the style.
- Modeling only the visible side at default yaw 45° — rotation is a core
  feature; every side must be valid.
- Scaling the object in the outliner rather than building at correct size.
- Building one megamesh with interior geometry the player can never see.
